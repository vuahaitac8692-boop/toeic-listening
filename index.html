Tạo bài học mới

Chọn audio trực tiếp từ iPhone/iPad (Files hoặc nguồn tệp iOS hỗ trợ). Ứng dụng sẽ gửi audio đến dịch vụ nhận dạng để tạo câu tiếng Anh có timestamp, sau đó dịch sang tiếng Việt. Bạn có thể sửa lại trước khi lưu.
Hỗ trợ MP3, M4A, WAV, AAC, OGG, FLAC, WebM. Tối đa 25 MB mỗi file cho bước tạo script.

Kết nối dịch vụ (thiết lập một lần)

Để giữ kín API key, ứng dụng dùng Cloudflare Worker làm trung gian. Không nhập OpenAI API key hoặc GitHub token trực tiếp vào website.

Mật khẩu chỉ được giữ trong phiên trình duyệt hiện tại. URL Worker được lưu trên thiết bị.

Cách ứng dụng lưu bài học

english-listening/
├── index.html
├── app.js
├── data/
│   └── lessons.json
└── lessons/
    └── ma-bai-hoc/
        ├── audio.mp3
        └── transcript.json

Khi cấu hình Worker và quyền GitHub xong, nút “Lưu bài học lên GitHub” sẽ tự upload audio, transcript và cập nhật danh sách bài học. Không cần mở GitHub trên iPhone để upload từng file.
